Fejlesztési Szemlélet és Architektúra

A projekt célja az volt, hogy külső, nehézkes keretrendszerek (pl. React, Angular) nélkül, tisztán Vanilla JavaScript használatával építsek fel egy komplex, állapottartó (stateful) alkalmazást.

  • check_circle Keretrendszer-független megközelítés: Mélyebb megértés a DOM manipuláció és a böngésző API-k terén.
  • check_circle Aszinkron adatkezelés: Promise-ok és Async/Await használata a Firebase és a REST API hívásoknál a blokkolásmentes UI érdekében.
  • check_circle Moduláris felépítés: Az alkalmazások különálló, de egymással integrálható logikai egységekre vannak bontva.
  • check_circle Biztonság és jogosultságok: Firebase Authentication alapú route- és adatvédelem.
